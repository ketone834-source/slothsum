# slothsum
A lazy summarizer powered by open weight Gemma and Ollama.
A lazy summarizer: paste long text, get two short sentences.
Built with Gemma 3 (1B), an open-weight model, run through Ollama in Google Colab. No API keys and no paid services.
How to run: open Google Colab, install Ollama, pull gemma3:1b, then run slothsum.py.
